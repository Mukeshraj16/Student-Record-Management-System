## Student Record Management System 
-This is a simple Java console application to manage student records. The system allows you to add, view, update, and delete student details using a menu-driven interface.

## Features
-Add Student (ID, Name, Marks)

-View All Students

-Update Student Details

-Delete Student Record

-Uses ArrayList to store student data

## How to Run
-Clone the repository.

-Compile the Java file:
-javac StudentManagementSystem_task2.java

## Run the program:

-java StudentManagementSystem_task2
## Technologies
-Java

-ArrayList

-OOP Concepts
